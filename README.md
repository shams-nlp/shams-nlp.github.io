# shams-nlp.github.io

Project page for SHAMS, an audio-grounded pronunciation benchmark for Levantine Arabic.
One static page (`index.html`, inline CSS, no scripts or external requests) built from sentences of the paper.
It gives the title, authors, links to the data and code, the abstract, the four tiers and four tasks, the composition table (Table 1), how to use, a citation and the license (§2.5).

- `index.html` page
- `shams-logo.png` mark, trimmed and set on a transparent ground
- `favicon.png` square version of the mark

The Paper link is left out until the arXiv link exists; add it to the link row then.

GitHub Pages serves the repository root on the `main` branch.
